# Description

This is the Backend part of the project we are doing as a group, it is meant to support the front end achieve its functionality by having the authorization processes for security and ensuring data of users, jobs and application are sent succesfully when needed.
Its made using flask and it interacts with react in the front end.
Each feature is organized clearly to make the project easy to understand and follow.
